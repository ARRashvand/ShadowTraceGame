# رد من — نمونه اولیه ۰.۲

هدف این نسخه آزمایش اولین حلقه زمانی و اولین سایه است.

## چیزهایی که باید امتحان شوند

1. تایمر با اولین حرکت بازیکن شروع شود، نه با بازشدن برنامه.
2. دور اول دقیقاً ۱۲ ثانیه باشد و مسیر بازیکن را ضبط کند.
3. پس از پایان زمان، بازیکن به نقطه شروع برگردد.
4. در دور دوم، سایه بنفش همان مسیر و مکث‌های دور اول را تکرار کند.
5. بازیکن بتواند هم‌زمان با سایه آزادانه مسیر دیگری را طی کند.
6. پس از پایان دور دوم، همان سایه برای آزمایش دوباره آماده شود.

در این نسخه سایه هنوز با بازیکن برخورد ندارد و کلید یا دروازه‌ای فعال نمی‌کند. این تعامل‌ها پس از تأیید دقت پخش مسیر اضافه می‌شوند.
